# NaotyVi.

A vim based editor to take a quick note in your terminal.

---

## Installation:

_If you have Cargo installed._

```bash
git clone https://github.com/NickyHariniaina/naotyvi.git
cd naotyvi
cargo install
```

If not... you can download the release based on your OS and add it in your $PATH.

## Usage.

Launch NaotyVi in interactive mode by typing `ntvim` in your terminal.

-- Direct command if you don't like interactive mode
`ntvim --config` to launch the configuration.
ntvim --config [flag] [value]: to directly configure something.
Avalaible value:
ntvim --config --bg [color] // RED, BLUE, WHITE, ect...
ntvim --config --home [folder] // Change your main note directory
ntvim --config --
